Focused desktop tools, with a little less in your way.

Cat Ninth is a GitHub organization based in Hungary, building lightweight alternatives to large desktop applications. The projects aim to keep work local where possible and make everyday tasks straightforward.

## Choose your tool

| If you want to… | Start with… |
| --- | --- |
| Understand a repository, review changes, and work with branches | [GitCat](gitcat/index.mdx), a visual Git client |
| Save recent gameplay or record your screen | [ClipCat](clipcat/index.mdx), a replay and recording tool |
| Check wireless device batteries from the Windows tray | [NapCat](napcat/index.mdx), a battery monitor for peripherals |
| Find an installer or learn about updates | [Downloads & updates](downloads.md) |
| Fix a problem or contribute | [Get help](help.md) |

GitCat and ClipCat have Windows x64 and Linux x86_64 packages. NapCat runs on Windows 10 and 11 and has an x64 installer. See [Downloads & updates](downloads.md) for the available formats.

## What you will find here

Short, task-based guides using the names you see in the applications. Start with installation, follow the first-use walkthrough, then return for settings and shortcuts when you need them.

The NapCat guides cover **0.1.6**, reviewed November 13, 2026. The guide images come from NapCat's own interface gallery and use simulated devices and battery history.

The October 25 review covers **GitCat 1.13.0** and **ClipCat 0.8.1**, plus ClipCat's [unreleased update-discovery fix](clipcat/settings-and-shortcuts.md#info-and-updates). GitCat images come from its project gallery and may show an earlier version. ClipCat images show its browser preview with sample settings and no live recording.

## More from Cat Ninth

The organization also maintains [CutCat](https://github.com/catninth/cutcat), a lightweight video editor, and the shared [desktop updater](https://github.com/catninth/updater).
