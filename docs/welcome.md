Focused desktop tools, with a little less in your way.

Cat Ninth is a GitHub organization based in Hungary, building lightweight alternatives to large desktop applications. The projects aim to keep work local where possible and make everyday tasks straightforward.

## Choose your tool

| If you want to… | Start with… |
| --- | --- |
| Understand a repository, review changes, and work with branches | [GitCat](gitcat/index.mdx), a visual Git client |
| Save recent gameplay or record your screen | [ClipCat](clipcat/index.mdx), a replay and recording tool |
| Find an installer or learn about updates | [Downloads & updates](downloads.md) |
| Fix a problem or contribute | [Get help](help.md) |

Both documented applications have Windows x64 and Linux x86_64 packages. Their platform capabilities differ; read the installation page for your tool before downloading. There are no published macOS packages for either tool.

## What you will find here

Short, task-based guides using the names you see in the applications. Start with installation, follow the first-use walkthrough, then return for settings and shortcuts when you need them.

The guides were checked against **GitCat 1.8.0** and **ClipCat 0.6.0** on September 26, 2026. GitCat images come from its project feature gallery and may show an earlier version. ClipCat images show the actual React interface in its browser preview with sample settings, without live recording.

## More from Cat Ninth

The organization also maintains [CutCat](https://github.com/catninth/cutcat), a lightweight video editor, and the shared [desktop updater](https://github.com/catninth/updater). This documentation currently covers GitCat and ClipCat.
