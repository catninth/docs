---
title: Browse your clips
description: Find, preview, play, reveal, and delete saved ClipCat videos.
---

Gallery brings the videos in your save folder into one view.

## Find a clip

Open **Gallery**, or press **Alt+Z**. Choose **All** or a game filter. **Other** contains captures without a recognized game. Use **Refresh** if files changed outside the application. Larger collections use **Previous** and **Next** pages.

Hover a clip for a preview, then select it to open the player. The player shows its name, game, date, and file size.

## Play or reveal a file

- **Show in folder:** reveal the current video in your file manager.
- **Open in player:** use your system's external video player.
- **Close** or **Esc:** return to Gallery.

The sidebar's **Open folder** opens your save folder. **Alt+F11** opens the most recent clip's folder; before any clip is saved, it opens the save folder instead.

## Delete a clip

In the player, select **Delete**, then confirm **Delete this clip?**. Check the selected filename first. This removes the video from the gallery and its saved location; it is not simply hiding a thumbnail. If deletion fails, close any player using the file and retry.

## An empty gallery

An empty gallery is normal before your first save. Enable replay, wait for it to capture footage, then save with **Alt+F10**. Alternatively, make and stop a manual recording. If a file still does not appear, confirm **Settings > Save folder**, use **Refresh**, and check the saved notification for errors.

ClipCat records and plays videos; trimming or assembling an edited video is a separate workflow. You can open saved files in your preferred editor.
