NapCat shows the batteries of your mice, keyboards, headsets, and controllers in the Windows notification area. Hover over a tray icon for a quick reading, or click it to see which device needs charging.

## What would you like to do?

| Task | Where to start |
| --- | --- |
| Keep one icon per device, or show only the most urgent one | [Use the tray and flyout](tray-and-flyout.md) |
| Find out whether your receiver, cable, or Bluetooth connection reports a level | [Check device support](devices.md) |
| Change when Windows warns you, or keep alerts quiet during a game | [Adjust settings and notifications](settings.md) |
| See how fast a battery drains and how much runtime to expect | [Read battery history](battery-history.md) |
| Find a missing icon or work out why a percentage is unavailable | [Troubleshoot NapCat](troubleshooting.md) |

NapCat runs on Windows 10 and 11. It can show a percentage only when the device or Windows supplies a battery reading. Adding an unsupported USB device by hand lets you track its connection; it does not unlock battery readings.
