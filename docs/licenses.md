License information belongs to each project. Consult the linked source before redistributing or modifying software.

## GitCat

GitCat publishes a [Mozilla Public License 2.0 license file](https://github.com/catninth/gitcat/blob/main/LICENSE).

## ClipCat

ClipCat's **Settings > Info > License** button currently links to the [MPL-2.0 license in the CutCat repository](https://github.com/catninth/cutcat/blob/main/LICENSE), as described in the [ClipCat README](https://github.com/catninth/clipcat#language-and-info).

At the documentation review on September 26, 2026, GitHub did not identify a license for the ClipCat repository itself. This guide records the link the application provides; it does not assign a license to the repository. For clarification, contact the project through [ClipCat issues](https://github.com/catninth/clipcat/issues).

## Documentation and dependencies

The documentation repository does not currently declare its own license. Application dependencies and capture components retain their respective licenses. See the relevant project repositories for their notices.
